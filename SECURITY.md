# Segurança

Se você encontrar uma vulnerabilidade no site ou no fluxo de download do Allm4, não publique detalhes exploráveis em issues públicas.

Envie o relato para **suporte@allm4.com** com:

- descrição do problema;
- passos mínimos para reproduzir;
- impacto observado;
- navegador e sistema operacional usados no teste;
- evidências que ajudem a validar o comportamento.

Relatos de boa-fé e testes que não prejudiquem usuários, disponibilidade ou dados são bem-vindos.
